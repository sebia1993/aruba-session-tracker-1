Rebuilding and replacement
--------------------------

The application source, pinned dependency locks, and build_windows.ps1 are in
the repository at the commit recorded in BUILD_INFO.json.  The package is a
PyInstaller onedir bundle rather than a one-file executable.  Qt, PySide6, and
Shiboken shared libraries remain separate under _internal/PySide6 and
_internal/shiboken6.  A recipient may replace interface-compatible shared
libraries or rebuild the application with a modified compatible LGPL library.
The project license does not add a prohibition on reverse engineering needed
to debug such modifications.

Paramiko is frozen into the packaged Python application.  Recombination is
therefore performed by rebuilding the exact application commit with the
replacement Paramiko source and the documented Python 3.13 build procedure.
