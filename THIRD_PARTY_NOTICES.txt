Aruba Session Tracker - Third-Party Notices
============================================

This distribution contains third-party software. The bundled CycloneDX file
"sbom.cdx.json" records the locked Python runtime dependencies and the native
runtime components declared by this build. "THIRD_PARTY_COMPONENTS.json" binds
the latter components to the exact files and SHA-256 values in this ZIP.
Windows system components remain outside that inventory. Copyright notices and
license texts supplied inside packaged libraries remain applicable. The
portable bundle's "licenses" directory contains per-component wheel evidence,
the CPython distribution license, the OpenSSL notice and license, and the full
LGPL-3.0-only/GPL-3.0 text used for the PySide6/Qt redistribution choice.

Transitive dependencies
-----------------------

Netmiko, Paramiko, PySide6 and the build tools bring additional transitive
components. Review both the CycloneDX SBOM and THIRD_PARTY_COMPONENTS.json
included with the release before deployment. This notice is informational and
does not replace any license text distributed by a component. It is not legal
advice and does not assert suitability for a particular distribution model.

The inventory and SBOM bind the files produced by one build. They do not
claim that separate ZIP builds are byte-for-byte reproducible. The CPython
patch version is recorded from the build interpreter rather than pinned as a
repository dependency; BUILD_INFO.json and the native inventory record the
version and hashes actually packaged.
